# UltraEdit Website Clone

This project is a front-end UI clone of the UltraEdit website. Built purely with HTML and CSS to practice Flexbox, Grid layouts, and pixel-perfect spacing.

**Tech Stack Used:**
* HTML5 for semantic structure
* CSS3 for styling, layout, and positioning

**What I Learned:**
* Linking external stylesheets
* Structuring layouts and navigation bars
* Working with custom SVG backgrounds and icons
* Using Git and GitHub for version control and hosting
  
**Challenges Faced & Overcome:**
* **Advanced Layouts:** Navigating the complexities of CSS Flexbox and CSS Grid, and learning exactly when to use a 1D row/column layout versus a 2D grid structure.
* **Pixel-Perfect Styling:** Replicating the exact padding, margins, and spacing of the original UltraEdit website to ensure the clone looked visually authentic and properly aligned.
