# UltraEdit Website Clone

This project is a front-end UI clone of the UltraEdit website. I built this completely from scratch to practice my core web development skills without relying on templates.

**Tech Stack Used:**
* HTML5 for semantic structure
* CSS3 for styling, layout, and positioning

**What I Learned:**
* Linking external stylesheets
* Structuring layouts and navigation bars
* Working with custom SVG backgrounds and icons
* Using Git and GitHub for version control and hosting
